# Search engines (SEO)

How the site tells Google, Bing and AI search tools what it is about.

## Where things live

| What | Where |
| --- | --- |
| Page titles, descriptions, canonical links, social preview tags, homepage structured data | `<!-- seo:start -->` block in each page's `<head>`, generated by `tools/seo.mjs` |
| Plain-HTML summary for visitors and crawlers without JavaScript | `<!-- seo-noscript:start -->` block at the top of `<body>` (homepage and doctor page), generated by `tools/seo.mjs` |
| Per-doctor title, description, canonical link and structured data | `setDoctorSeo` in `DoctorProfilePage.dc.html` (runs in the browser) |
| `sitemap.xml`, `robots.txt` | generated by `tools/seo.mjs` |
| Favicon, app icons, social preview image | `assets/brand/` |

Do not edit the generated blocks by hand. Change `tools/seo.mjs` (or the doctor data in
`DoctorProfilePage.dc.html`), then run:

```
node tools/seo.mjs
```

## When to re-run `node tools/seo.mjs`

- The site moves to its own domain: change `SITE_URL` first.
- The clinic address, phone or opening hours change: change `CLINIC` (and the same text on the homepage).
- A doctor is added or removed in `DOCS` in `DoctorProfilePage.dc.html`.
- You get a verification code from Google Search Console or Bing Webmaster Tools: paste it into
  `GOOGLE_SITE_VERIFICATION` / `BING_SITE_VERIFICATION`.

## Rules

- Structured data only repeats facts that the page shows. No ratings or reviews markup
  (Google does not show self-published clinic reviews, and the numbers must be real).
- `Booking Flow` and `Patient Dashboard` are private steps and carry `noindex`; they are not in the sitemap.
- Stand-alone pages listed in `STATIC_PAGES` (the discount page, magazine articles) keep their own `<head>`. They join the sitemap automatically once their `noindex` tag is removed; re-run the script then.
- `index.html` and `Booking platform.dc.html` are the same page; both declare the site root as canonical.
